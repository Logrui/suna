   model_loading
   └─ Model is loading (show spinner, toast)
   
   model_loaded
   └─ Model ready to use (success toast with time)
   
   model_load_failed
   └─ Loading error occurred (error toast with details)
   
   model_unloading
   └─ Model being unloaded (quiet update)
