# Slash Commands: Example Markdown Files

These are example Markdown files that you can place in your `Knowledge/prompts/` directory to test the slash commands feature.

---

## 1. `summarize.md`

```markdown
---
description: "Summarize content into 5 bullet points."
---

Summarize the following content in 5 bullet points, focusing on key takeaways and important numbers or dates.
```

---

## 2. `draft-email.md`

```markdown
---
description: "Draft a professional email."
---

Draft a professional email for the following scenario. Keep it to 2-3 paragraphs, use a formal tone, and include a clear call-to-action.
```

---

## 3. `brainstorm.md`

```markdown
---
description: "Generate 10 creative ideas."
---

Generate 10 creative ideas for the following topic. Be diverse, think outside the box, and explain each idea briefly.
```

---

## 4. `explain-simple.md`

```markdown
---
description: "Explain complex concepts simply."
---

Explain the following in simple terms that a 10-year-old could understand. Avoid technical jargon and use real-world examples if possible.
```

---

## 5. `code-review.md`

```markdown
---
description: "Review code for improvements."
---

Review the following code. Check for bugs, performance issues, security vulnerabilities, and suggest improvements and refactoring opportunities.
```

---

## 6. `create-todo.md`

```markdown
---
description: "Create a structured TODO list."
---

Create a structured TODO list for the following task. Break it down into smaller, actionable steps with estimated effort levels (easy/medium/hard).
```

---

## How to Use These Examples

1.  **Create the directory**: Ensure you have a `Knowledge/prompts/` directory in your user workspace (e.g., `D:\Homelab\suna\Knowledge\prompts/`).
2.  **Save files**: Save each example above as a `.md` file in that directory (e.g., `summarize.md`, `draft-email.md`).
3.  **Test**: Start your frontend application and try typing `/summarize` or `/draft-email` in the chat input.
